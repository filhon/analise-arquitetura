🎭 Demonstração de Diálogos Personalizados

Sistema completo de diálogos que substitui alert(), confirm() e prompt() nativos do navegador.

1. Diálogo de Confirmação (Confirm)

Diálogo com dois botões: Confirmar e Cancelar. Retorna boolean.

const confirmed = await dialogService.confirm({ title: "Confirmar Ação", message: "Tem certeza que deseja continuar?", confirmText: "Sim, Continuar", cancelText: "Cancelar", icon: "help", });

2. Diálogo com Input (Prompt)

Diálogo com campo de texto. Retorna string ou null se cancelado.

const value = await dialogService.prompt({ title: "Digite um valor", message: "Insira o texto desejado:", placeholder: "Digite aqui...", confirmText: "Enviar", cancelText: "Cancelar", icon: "edit", });

3. Diálogo de Alerta (Alert)

Diálogo com apenas um botão (OK). Usado para notificações simples.

await dialogService.alert({ title: "Operação Concluída", message: "Os dados foram salvos com sucesso!", confirmText: "OK", icon: "check_circle", });
