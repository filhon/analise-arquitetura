## ❓ FAQ RÁPIDO

### Preciso pagar algo?

**Não!** Plano gratuito é suficiente. Até 10GB/mês grátis.

### Quanto tempo leva para configurar?

**13 minutos** (5 min Firebase + 2 min copiar + 1 min colar + 5 min testar)

### Funciona offline?

**Sim!** Firebase tem queue automático. Sincroniza quando voltar online.

### É seguro?

**Sim!** Para testes, use modo aberto. Para produção, configure autenticação.

### Quantos dispositivos suportam?

**Ilimitado!** Plano gratuito permite 100 conexões simultâneas.

### Preciso de servidor?

**Não!** Firebase é serverless. Google cuida de tudo.
