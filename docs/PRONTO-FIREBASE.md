## 🐛 SE DER ERRO

Veja o console (F12):

**❌ "Permission denied"**
→ Firebase Console → Regras → Modo teste

**❌ "Sincronização: INATIVA"**
→ Verificar internet e credenciais

**❌ Não sincroniza**
→ Limpar cache (Ctrl+Shift+Del)
